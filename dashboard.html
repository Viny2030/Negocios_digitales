Esta plataforma tiene 3 productos, cada empresa cliente con su propia API key. DynamicPricing y SmartRoute son stateless: cada request se resuelve de punta a punta con los datos que trae (optimización matemática, sin modelo que entrenar). LeadMatch sí entrena un clasificador por empresa a partir de un dataset subido; mientras no haya uno entrenado, usa una heurística de respaldo.

Pasos: 1) Pedí tu API key al equipo (identifica tu empresa). 2) Pegala arriba y tocá "Conectar y cargar API" — esto lee la documentación técnica de la API y arma los formularios automáticamente. 3) Elegí la pestaña del producto que querés probar. 4) Para LeadMatch, además de Probar tenés Entrenar y Datasets para subir tu histórico de leads.

Cómo leer una respuesta: los campos JSON siguen el schema documentado en /docs. En LeadMatch, used_default_scoring: true indica que todavía no hay modelo entrenado para esa empresa y se usó la heurística de respaldo.

Se guarda solo en tu navegador (localStorage), nunca queda en pantalla salvo que toques el ícono.

Si abriste este archivo con doble-click (file://) y el fetch falla por CORS, serví la carpeta con python -m http.server 8080 y abrí http://localhost:8080/dashboard.html.
