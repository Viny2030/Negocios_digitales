Esta plataforma tiene 4 modelos de IA (Reinforcement Learning), uno por caso de negocio. Cada empresa cliente tiene su propia API key y sus propios modelos entrenados — la key identifica a qué empresa pertenecen los datos y las recomendaciones.

Pasos: 1) Pedí tu API key al equipo (identifica tu empresa). 2) Pegala arriba y tocá "Conectar y cargar API" — esto lee la documentación técnica de la API y arma los formularios automáticamente. 3) Elegí la pestaña del caso que querés probar. 4) Dentro de esa pestaña: Datasets para subir tus datos históricos, Entrenar para generar un modelo con esos datos, y Probar inferencia para pedirle una recomendación al modelo ya entrenado con datos de ejemplo (editá el JSON con datos reales de tu negocio).

Cómo leer una respuesta: rationale explica en lenguaje simple por qué el modelo recomendó eso. constraints_applied muestra qué reglas de negocio (límites, políticas) ajustaron la sugerencia cruda del modelo. Campos como expected_value, priority_score o false_positive_probability son puntajes de confianza del modelo — sirven para priorizar, no son una garantía absoluta.

Si abriste este archivo con doble-click (file://) y el fetch falla por CORS, serví la carpeta con python -m http.server 8080 y abrí http://localhost:8080/dashboard.html.
